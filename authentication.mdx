title: "Authentication"
description: "Every request to the GoStudio API is authenticated with your API key, sent as a bearer token."
---

## How it works

Send your API key as a bearer token in the `Authorization` header on every request:

```
Authorization: Bearer <api_key>
```

<CodeGroup>
```bash curl
curl https://www.gostudio.ai/api/v2/my/credit-balance \
  -H "Authorization: Bearer <api_key>"
```

```javascript Node.js
const res = await fetch("https://www.gostudio.ai/api/v2/my/credit-balance", {
  headers: { Authorization: "Bearer <api_key>" }
});
```

```python Python
import requests

res = requests.get(
    "https://www.gostudio.ai/api/v2/my/credit-balance",
    headers={"Authorization": "Bearer <api_key>"},
)
```
</CodeGroup>

## Get your API key

<Steps>
  <Step title="Log in to GoStudio">
    Go to [gostudio.ai](https://www.gostudio.ai) and log in.
  </Step>
  <Step title="Open your profile">
    Click your **Profile**.
  </Step>
  <Step title="Open Account settings">
    Choose **Account settings**.
  </Step>
  <Step title="Generate API key">
    Click **Generate API key**, then copy it.
  </Step>
</Steps>

GoStudio → Login → Profile → Account settings → Generate API key

<Warning>
  Keep your API key secret. Never put it in client-side code, a public repository or a shared document. If it is exposed, generate a new one.
</Warning>

## Missing or invalid key

A request without a valid key returns `401`:

```json
{
  "status": 401,
  "error": {
    "type": "authentication_error",
    "code": "unauthorized",
    "message": "Missing or invalid token."
  }
}
```

A key that is not allowed on an endpoint returns `403 forbidden`.
