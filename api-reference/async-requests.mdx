---
title: "Asynchronous requests"
description: "Run jobs in the background, poll for the result, and get a webhook when they finish."
---

Every generation request creates a **job**. You choose how to wait for it with `mode`:

- **`sync`:** the request waits for the result, up to 270 seconds.
- **`async`:** you get a `job_id` and a `poll_url` straight away, and the job runs in the background.

If a `sync` request runs out of time, it returns `202` like an `async` request, and the job keeps running.

## Choosing a mode

| Endpoint | Default `mode` |
|---|---|
| Age Modifier, Watermark Remover, Weight Shift, Image create, Image edit | `sync` |
| Group Photo, Recreate, Profile Photo, Recreate Group | `async` |
| All Video endpoints | Always `async` |

Video takes only `async`, or leave `mode` out. Watermark Remover with `model_id: "lite"` always answers `200` with the result, even with `mode: "async"`.

Use `async` for anything you don't want to hold a connection open for, and for many jobs at once. Use `sync` for fast tools, where the result comes back in the same response.

## How async works

<Steps>
  <Step title="Submit the job">
    Send the request with `mode: "async"`. You get `202` straight away.

    <CodeGroup>
    ```bash curl
    curl -X POST https://www.gostudio.ai/api/v2/recreate \
      -H "Authorization: Bearer <api_key>" \
      -H "Content-Type: application/json" \
      -d '{
        "input_image_url": "https://example.com/me.jpg",
        "reference_image_url": "https://example.com/style.jpg",
        "mode": "async"
      }'
    ```

    ```python Python
    import requests

    API = "https://www.gostudio.ai/api/v2"
    HEADERS = {"Authorization": "Bearer <api_key>"}

    job = requests.post(f"{API}/recreate", headers=HEADERS, json={
        "input_image_url": "https://example.com/me.jpg",
        "reference_image_url": "https://example.com/style.jpg",
        "mode": "async",
    }).json()["data"]
    ```
    </CodeGroup>

    ```json
    {
      "status": 202,
      "data": {
        "job_id": "3f2b8c1e-5d4a-4c1b-9e7a-0a1b2c3d4e5f",
        "status": "processing",
        "credits_deducted": 10,
        "poll_url": "https://www.gostudio.ai/api/v2/jobs/3f2b8c1e-5d4a-4c1b-9e7a-0a1b2c3d4e5f"
      }
    }
    ```

    <Warning>
    Do not send the request again after a `202`. The job is still running, and a second request creates a second job and is charged again.
    </Warning>
  </Step>

  <Step title="Poll for the result">
    Call `poll_url` (or [Get job](/api-reference/jobs/get-job-poll)) every 5 seconds until `status` is no longer `pending` or `processing`.

    <CodeGroup>
    ```bash curl
    curl https://www.gostudio.ai/api/v2/jobs/3f2b8c1e-5d4a-4c1b-9e7a-0a1b2c3d4e5f \
      -H "Authorization: Bearer <api_key>"
    ```

    ```python Python
    import time

    while True:
        result = requests.get(job["poll_url"], headers=HEADERS).json()["data"]
        if result["status"] not in ("pending", "processing"):
            break
        time.sleep(5)
    ```
    </CodeGroup>

    | `status` | Meaning |
    |---|---|
    | `pending`, `processing` | Still running. Keep polling. |
    | `completed` | Done. The files are in `output_urls`. |
    | `failed` | Read `error`. Your credits are returned. |
    | `abandoned` | The job was stopped. No result will come. |
  </Step>

  <Step title="Or use a webhook (optional)">
    Send a `webhook_url` and we `POST` to it once when the job finishes. It works in both modes, and polling still works alongside it.
  </Step>
</Steps>

## Webhooks

Add `webhook_url` to any generation request.

```json
{
  "event": "job.completed",
  "job_id": "3f2b8c1e-5d4a-4c1b-9e7a-0a1b2c3d4e5f",
  "status": "completed",
  "tool_name": "recreate",
  "output_urls": ["https://…/result.jpg"]
}
```

A failed job sends `"event": "job.failed"`, `"status": "failed"` and an `error` object instead of `output_urls`.

- The URL must be public `https` on port 443, with no username or password, and up to 2048 characters.
- We do not follow redirects.
- If your server does not answer with `2xx` (timeout, network error, `408`, `429` or `5xx`), we try again, 5 attempts in total over about 90 seconds.

<Warning>
Webhooks are not signed yet. When one arrives, confirm the result with [Get job](/api-reference/jobs/get-job-poll) before you use it.
</Warning>
