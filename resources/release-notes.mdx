<Update label="November 2026" description="GoStudio API v2" tags={["New"]}>
  GoStudio API v2 is available.

  **Apps**
  - Age Modifier, Watermark Remover, Weight Shift and Group Photo.

  **AI Image**
  - Create images from a prompt, edit images with a prompt, and list the available models.

  **AI Video**
  - Create a video from a prompt, from keyframes or from reference images, edit an existing clip, and list the available models.

  **Recreate**
  - Recreate a photo, create a Profile Photo and recreate a group scene with your trained profiles.

  **Account**
  - List your profiles, check your credit balance and history, and read your generations, images and uploads.

  **Platform**
  - One response format for every endpoint, with `sync` and `async` modes and optional webhooks.
  - Credits are charged when a job is accepted and returned automatically if it fails.
</Update>
